# U-Ticaret Frontend (React + Vite)

Bu klasor, e-ticaret projesinin React/Vite tabanli SPA frontend'idir.

## Calistirma

```bash
npm install
npm run dev
```

Uygulama: `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```

## Env

`VITE_API_URL` (opsiyonel):

```env
VITE_API_URL=http://localhost:5000/api
```

Deger verilmezse default `http://localhost:5000/api` kullanilir.
